## VRmin 0.60

### Mac: Vulkan games with real SteamVR
- **Vulkan games work with real SteamVR.** Games that draw with Vulkan, like **DOOM VFR**, now show up in the headset with real SteamVR instead of falling back to OpenComposite. Their image goes to SteamVR through Metal, and VRmin fixes the shaders and depth formats Macs can't run as they are (DOOM VFR was all black).
- **Half-Life 2: VR Mod opens in VR with real SteamVR.** Its own DXVK now starts on Apple GPUs, and 32-bit games can share their image with SteamVR. It's still heavy on the Mac's CPU, so expect it to be slow for now.
- **SteamVR's menu closes by itself** when the game starts, so there's no need to press **Resume**.
- **The headset's loading screen says when SteamVR is opening**, since the game takes a bit longer then.
- **Fixed: text drawn by Windows was missing** in some games, like Half-Life 2: VR Mod's menu.

### Mac: your fingers in real SteamVR
- **Hand tracking with real SteamVR.** When you put the controllers down, SteamVR games that support finger tracking get your real hands and fingers from the Quest. Pick the controllers up again and they're back. VRmin's own hands over the game still only show when **Real hands** is on.
- **The refresh rate changes live** with real SteamVR: switching between 72, 80, 90 and 120 Hz in the Quest applies right away, without restarting the game.

### Mac: installing games
- **VRmin asks where to install a game.** Pick any of your Steam libraries (with their free space), or another folder or an external drive, which becomes a new Steam library.
- **Fixed: the engine download could stall** on a slow connection. It now resumes where it left off.

### Mac: fixes
- **VRmin no longer needs Apple's developer tools.** It brings its own Python now: on a Mac without them, macOS kept asking to install them and the 6-digit code never showed up.
- **Fixed: Steam's window stayed open** after closing a game. It hides again when the last game closes, with any VR system.
- **Show / Hide Steam.** Showing Steam's window keeps it open until you hide it again with the same button.
- **Fixed: DOOM VFR didn't start.** It asks the GPU for Vulkan features Macs don't have, and VRmin now leaves those out.
- **The Windows engine has an update**: VRmin asks you to complete it once, with one click (your games and Steam stay as they are).
- **Games from outside Steam can be added by their `.bat`**, for games that start from one.

### Quest app 0.86
- **Sends your finger tracking to real SteamVR** when you're not holding the controllers.
- **With real SteamVR, the game menu doesn't offer Index or Vive emulation**: SteamVR handles the controllers there, with its own controller bindings.
