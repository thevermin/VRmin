## VRmin 0.52

VRmin now builds its own OpenComposite, smoother games, and menus that face the right way.

### Games
- **Menus no longer show mirrored.** In games like Kayak VR: Mirage, a menu could appear backwards (text reversed) depending on which way you were facing. Menus now keep the exact position and rotation the game gives them, like on a PC.
- **Smoother frames.** VRmin Host takes each frame from the game sooner, so games like Beat Saber drop fewer frames before they reach the headset.
- **Less work per frame for SteamVR games.** The image of each eye now goes from the game to VRmin without an extra copy, and menus that don't change aren't read again every frame.

### OpenComposite, built by VRmin
- OpenComposite (what lets SteamVR games run with VRmin) is now built by VRmin from [GameNative's source](https://github.com/GameNative/opencomposite) and comes inside VRmin Host, instead of being downloaded when installing the engine. This lets VRmin fix and improve it directly.
- The report now includes how long OpenComposite takes on each frame, to keep improving performance.
