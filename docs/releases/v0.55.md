## VRmin 0.55

### Mac
- **The Lab: Robot Repair works.** It was completely black (with sound) on fast Macs and didn't show at all on others. Three things were fixed:
  - Robot Repair asks for 8x antialiasing, and Apple GPUs only go up to 4x, so it drew black. VRmin's DirectX → Metal translation (DXMT) now uses 4x when a game asks for more than the Mac can do.
  - It's a second program that The Lab opens while it stays open, and both used the same shared file to send frames to the Mac. Each program now has its own.
  - The Mac could stop accepting new connections from games while that second program ran. That can't happen anymore.
- **The Lab's loading screens look right.** The big title cards now float over black like on SteamVR, instead of over the frozen last frame, and the huge tilted "LOADING... THE LAB" picture in front of your face is gone.
- **"Loading…" only shows on real loads.** When a game stops sending frames, the headset keeps showing the last one as before, but it only darkens it with "Loading…" after 3 seconds, so short hitches don't break immersion.
- **Kayak VR: Mirage shows its controllers and laser pointers in the pause menu.** The game only draws them for HTC Vive controllers, so VRmin now turns on **Emulate HTC Vive controllers** for it by default. If you turned that option off for Kayak VR yourself, turn it back on: in **VRmin Host › Games**, click the settings button on the game's cover › **Quality and performance for this game…**, or in the Quest menu while playing, under **Controls**. Reopen the game after changing it.
- **"Something's wrong" reports include the games' own logs** (Unity and Unreal), to find problems faster.
- The first time you open a game after updating, VRmin installs its new DXMT (about 20 MB). Steam and your games are kept.

### Windows (beta)
- The same "Loading…" change: it only shows after 3 seconds without frames.
- A game that opens another VR program while it stays open (like The Lab with Robot Repair) now works: each program has its own shared memory.

### Quest app
- When VRmin can't show the desktop of a PC, the headset now shows the real reason instead of the Mac's screen recording message.
