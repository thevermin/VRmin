## VRmin 0.55

### Mac
- **Kayak VR: Mirage shows its controllers and laser pointers in the pause menu again.** The game only draws them for HTC Vive controllers, so VRmin now turns on **Emulate HTC Vive controllers** for it by default. If you turned that option off for Kayak VR yourself, turn it back on: in **VRmin Host › Games**, click the settings button on the game's cover › **Quality and performance for this game…**, or in the Quest menu while playing, under **Controls**. Reopen the game after changing it.

### Downloads
- `VRmin.Host.0.55.zip`: the Mac app
- `VRmin-0.81.apk`: the Quest app (no changes)
- `VRmin.Windows.0.3.zip`: the Windows app (beta, no changes)
