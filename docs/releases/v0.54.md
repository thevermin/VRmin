## VRmin 0.54

### Mac
- **Games that change level by opening a new session no longer go black.** In The Lab, experiences like Robot Repair showed a black screen (with sound) after leaving the hub. The faster "direct copy" of the game's image is now used only in the first session, and the next ones use shared memory, which works the same.
- **No more giant signs in The Lab.** Signs and panels a game fades out (like the ones in The Lab's hub) stayed on screen at full size and in front of everything. Now they hide when the game hides them, and wide panels keep their shape instead of showing as huge squares.
- If the Mac takes a moment to accept the shared memory, the game tries again instead of falling back to the network, where big images didn't fit and the screen stayed black.
