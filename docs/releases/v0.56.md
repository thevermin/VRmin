## VRmin 0.56

### Mac
- **Fixed: after updating to 0.55, VRmin could get stuck on "Updating the Windows to the new engine".** If Steam was still open from before, the update waited for it to close forever. VRmin now closes Steam and any other program in its Windows before updating, and never waits forever.
  If you're stuck there: quit VRmin Host, install this version and open it again. If it's still stuck, restart your Mac and open VRmin Host. Steam and your games are kept.
- **VRmin installs Rosetta 2 by itself.** The engine needs Apple's Rosetta 2, and before you had to install it from Terminal. Now, when you install the engine, your Mac asks for your password in its own window and Rosetta gets installed.
- **If a task fails (like installing the engine), the log opens by itself** so you can see why. Before, it only left a line in the collapsed log at the bottom and it looked like nothing happened.
- **"Something's wrong" reports include the engine and Steam installer logs.**
