## VRmin 0.56

### New: VRmin for Linux (beta)
- Stream your Steam VR games (with Proton) from a Linux PC to the Quest, like on Windows. Download `VRmin.Linux.0.1.tar.gz`, extract it and open `vrmin-host`. The `README.txt` inside says what it needs. It's the first version and hasn't been tested on many PCs yet: if something doesn't work, please open an Issue and attach `~/.local/share/VRmin/VRmin.log`.

### Mac, Windows and Linux
- **Controller vibration.** When a game makes your controllers vibrate (hits, shots, grabbing things), you now feel it on the Quest controllers. Needs the new Quest app (0.83).

### Mac
- **Fixed: after updating to 0.55, VRmin could get stuck on "Updating the Windows to the new engine".** If Steam was still open from before, the update waited for it to close forever. VRmin now closes Steam and any other program in its Windows before updating, and never waits forever.
  If you're stuck there: quit VRmin Host, install this version and open it again. If it's still stuck, restart your Mac and open VRmin Host. Steam and your games are kept.
- **VRmin installs Rosetta 2 for you.** The engine needs Apple's Rosetta 2, and before you had to install it from Terminal. Now, if it's missing, VRmin Host says so at the top and shows an **Install** button in the first-time steps. Installing the engine also installs it. Your Mac asks for your password in its own window.
- **If a task fails (like installing the engine), the log opens by itself** so you can see why. Before, it only left a line in the collapsed log at the bottom and it looked like nothing happened.
- **"Something's wrong" reports include the engine and Steam installer logs.**
