## VRmin 0.58

### Mac: real SteamVR, much better (beta)
You can now play with the real SteamVR, like on a Windows PC, instead of OpenComposite. It's usually the most stable option, but it uses more memory and takes a bit longer to open.
- **SteamVR's menu in the headset**, with your Steam library, SteamVR's controller profiles and its settings. It opens before the game, so the game starts with everything ready.
- **Vibration** works in every game.
- **SteamVR's own resolution setting works**, measured against your Quest's real resolution (it starts at 25%).
- **How to use it:** install SteamVR from VRmin's Steam (Library › Tools), then in VRmin Host open a game's menu (the sliders button) › **VR system** › **Real SteamVR**.
- **Automatic mode uses it by itself** when an OpenVR game doesn't start with OpenComposite. The same menu now has a tip: if a game doesn't work well with OpenComposite, try real SteamVR; if real SteamVR is slow or won't open, try OpenComposite.
- **Open SteamVR on its own**, like putting on a Valve Index: SteamVR's room and menu, and you open your games from there. There's an **Open SteamVR** button in VRmin Host › Games, and SteamVR is the first tile in the Quest's game list.
- **No more "SteamVR isn't set as the default OpenXR runtime" message**: 32-bit OpenXR games also go to SteamVR.

### Mac: faster and smoother
After updating, VRmin Host asks you to install the new engine version (**Install** on "Windows games engine"). Steam, your games and your saves are kept.
- **msync in the engine** (from CrossOver): Windows programs no longer wait in a single line to talk to each other. In our tests with SteamVR, each game frame took half the CPU time, and SteamVR's own work went from 11 ms to 2.5 ms per frame.
- **Steam's interface is drawn with the GPU** instead of the CPU: smoother, and more CPU left for your games.
- **Less memory with real SteamVR**: hidden windows and other headsets' drivers that VRmin never uses aren't loaded anymore. On Macs with 8 GB this makes a big difference (fewer stutters when you turn your head).
- **VRmin's SteamVR driver uses less CPU.**

### Mac: fixes
- **Fixed: Steam could freeze when SteamVR opened**, and showed a SteamVR "shared lib not found (102)" error.
- **Fixed: Half-Life 2: VR Mod's menu** with OpenComposite.
- **Games you didn't install don't show up anymore.** Steam sometimes downloads part of another game by itself (like Half-Life 2: Lost Coast with Half-Life 2), and VRmin listed it as a game.
- **Steam no longer looks open forever** after updating itself, and its window no longer stays invisible after Steam's first update.
- **Quitting VRmin Host also closes Steam** and everything running in VRmin's Windows.
- **Turning the Quest off with SteamVR open no longer makes the Mac sluggish.**
- **New switch for Steam friends and chat** (Settings › This Mac), off by default as before: with them on, Steam uses almost a full CPU core.
- **Safer connections**: wrong pairing codes pause pairing for a while, the browser page can no longer control your Mac, and settings are only accepted from your own Mac.

### Quest app 0.84
- **Soft vibration in VRmin's menus**: a light tap when you point at a new button, and a slightly stronger one when you click or grab a window.
