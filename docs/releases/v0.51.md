## VRmin 0.51

Smoother microphone, sharper Medium quality.

### Microphone
- The Quest's microphone sounds smoother in games: VRmin now keeps a slightly bigger buffer so the voice doesn't cut out when the Wi-Fi delivers audio in bursts.
- If the voice still cuts out, the report now says how often it happened, so it can be tuned further.

### Quality
- **Medium** is now 1280 pixels per eye (it was 1024), for a sharper image on most Macs. If you were using Medium, choose it again in Settings to get the new value.

### Games
- The report now lists the menus and panels each game shows, to help fix games whose menus can't be used yet.

### Downloads
- `VRmin.Host.0.51.zip`: the Mac app
- `VRmin-0.80.apk`: the Quest app
- `VRmin.Windows.0.2.zip`: the Windows app (beta)
