# DXMT patches from steamac

These patches come unchanged from [fxgl/steamac](https://github.com/fxgl/steamac) (`host/dxmt/patches`, commit
79aeadb, Apache-2.0; they were exported from the StonkGuy/dxmt branch `steamac`). They apply in order on
3Shain/dxmt e94c312 (the base steamac pins), before VRmin's own patches in `mac/dxmt/`.

DXMT at that revision is LGPL-2.1-or-later, and so is VRmin's DXMT build: its source is this base, these patches and
VRmin's, all public. See `.github/workflows/dxmt.yml`.
